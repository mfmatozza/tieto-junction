Questions reviewers ask

Does the AI decide what is safe to merge?

No. The AI only explains the change. Code checks each claim against the diff, the issue and the test results. A named person signs every merge and writes down the risk they accept.

What if the tests are weak?

Then less folds away. Code that no passing test covers stays open, and risky areas like public API, wire formats and generated files are always shown, even when tests pass.

Do I need Lanes to use Vouch?

No. Without Lanes, every change is reviewed as written by an unknown agent, so nothing is trusted by default. With Lanes, trust is earned per agent and per area of the code.

Which stacks does it run on today?

.NET repositories on GitHub. The Guardrail runs your existing test projects on the base and the branch in separate worktrees.
