Lanes, Vouch and Aiven. What runs where.

Lanes coordinates the agents that write the code. Vouch checks what they wrote. Aiven keeps the permanent record and the live state of every review.

Questions reviewers ask

Does the AI decide what is safe to merge?

No. The AI only explains the change. Code checks each claim against the diff, the issue and the test results. A named person signs every merge and writes down the risk they accept.

What if the tests are weak?

Then less folds away. Code that no passing test covers stays open, and risky areas like public API, wire formats and generated files are always shown, even when tests pass.

Do I need Lanes to use Vouch?

No. Without Lanes, every change counts as written by an unknown agent, so nothing is trusted by default. With Lanes, agents work in parallel without collisions and trust is earned per agent and per area of the code.

Why Aiven?

A review is shared and live. Postgres keeps the record, Kafka lets other tools react to each vote and sign-off, and Valkey holds who is reviewing right now. Aiven runs all three as managed services.

Which stacks does it run on today?

.NET repositories on GitHub. Guardrail runs your existing test projects on the base and the branch in separate worktrees.
